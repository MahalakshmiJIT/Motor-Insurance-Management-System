# Motor Insurance Management System

A relational database project developed using MySQL to efficiently handle end-to-end motor insurance operations, including policy administration, vehicle tracking, claims management, and settlement workflows.

## Key Features
- Customer & Vehicle Profiling: Manages owner information and links multiple vehicles to individual customer profiles.
- Policy & Coverage Administration: Tracks policy types, sum insured, premium amounts, start/end dates, and renewal status.
- Claims & Settlement Workflow: Records claim details, tracks claim statuses, assigns adjusters, and coordinates with repair workshops.
- Financial Tracking: Maintains transaction histories for premium payments, claim payouts, and workshop service fees.
- Data Integrity: Enforces relational constraints (PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE) to preserve data accuracy across all interconnected tables.

## Database Schema & SQL Concepts Used
- Relational Database Design: Structured tables covering Customers, Vehicles, Policies, Claims, Payments, Adjusters, Workshops, and Renewals.
- SQL Operations: Data Definition Language (DDL) for table creation and Data Manipulation Language (DML) for record handling.
- Complex Queries: Multi-table INNER/LEFT JOINs, subqueries, group aggregations, and conditional filtering.

## Tech Stack & Tools Used
- Database Engine: MySQL
- GUI Tool: MySQL Workbench
- Version Control: Git, GitHub
